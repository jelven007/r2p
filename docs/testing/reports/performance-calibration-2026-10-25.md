# 性能模型与 CI 成本采集

日期：2026-10-25；R-07 工具实施与本地扩大采样完成。
真实用户负载、独占且稳定的运行环境和连续 20 次远端 CI 成本验收仍未完成。

## 工作量和采样

`tools/perf-probe` 增加 fixed_total / fixed_per_thread。
前者把同一迭代总量分摊到 1/2/4/8 线程并分配余数；后者保持每线程迭代数。
调用/附着/分离按调用计，64 对象延迟释放按对象计；计时前每线程预热 100 次。
通过 1,001 次迭代的实际运行验证非整除工作量；工具拒绝漏场景、漏模型、重复组合或计量错误。

运行采样 `--samples` 与编译成本采样 `--build-samples` 分离。
`--runtime-only --threaded-only` 每种解释器只编译两个 minimal 二进制，测 16 个并发场景。
单次编译保存在 runtime_setup，不能作为独立编译成本比较。
完整编译模式仍要求至少三次独立 clean 样本并保留 consumer-edit / sdk-edit。
schema 1 的既有 204 条运行及 54 条编译样本保持原始文件和数值，schema 2 的报告读取使用新计量规则。
新生成器已用原 schema 1 数据复验。

基线/候选按 ABBA 次序运行，记录独立进程、次序、负载、二进制摘要与执行时 GIL。
CV 超过 10% 标为调查信号；不作正式发布门限。
同一机器、离线缓存、同一依赖锁和解释器，不代表独占 CPU 或固定频率。
本轮选择 20 轮 × 两个源码 × 16 场景，每种解释器 640 条样本。

两种解释器完整采样的源码为 `31e4f820db74b8992a378d476fcf266d925ee9e7`，基线 `3a24917eb2766aa8ded8c04fefde1c1d4b133c00`。
两模式共 1,280 条运行样本、80 个独立进程与四次仅用于准备运行的编译；未重复旧编译成本采样。
每模式内基线与候选锁摘要相等，执行 GIL 状态与配置相符。
完整值、进程负载、二进制/工具摘要见[数据](../data/performance-calibration-2026-10-25.json)。
本地日志在 `target/optimization/performance-calibration-{gil-20261025,ft-20261025-v2}/`。
GIL 模式的候选中位数差约 −1.9% 到 +1.4%；32 组基线/候选统计中五组 CV 超过 10%。
这个范围只描述当前合成嵌入负载，不证明通用加速或 5% 门限。
FT 首次启动传错了不存在的完整 SHA，尚未产生测量；失败目录保留，随后使用实际 SHA 重跑。
工具增加了创建输出目录前的本地提交存在性检查。

FT 的 32 组基线/候选统计中 17 组 CV 超过 10%。
四线程样本如下；Δ 为候选/基线中位数 − 1。

| 工作量模型 | 场景 | 基线 CV | 候选 CV | Δ |
| --- | --- | --- | --- | --- |
| fixed_total | 调用/附着/分离 | 24.3% | 22.7% | +9.6% |
| fixed_per_thread | 调用/附着/分离 | 32.9% | 21.7% | +0.4% |
| fixed_total | 64 对象延迟释放 | 13.2% | 17.8% | −3.9% |
| fixed_per_thread | 64 对象延迟释放 | 26.9% | 27.8% | +1.0% |

这些结果没有重现旧三次四线程调用的 +139.6%，但噪声仍大，不能由此宣称问题已消失或锁算法已优化。
继续保留内核同步实现；下一步是独占/固定条件环境与真实业务负载。
本轮没有建立 5% 正式阻断门限，也没有以多次样本替代硬件和业务验收。

## CI 成本的事实边界

`ci_cost.py` 读取真实 Actions 导出的 run/jobs 和 total_jobs。
已完成失败任务也计入实际任务占用；跳过任务占用为零。
报告区分 created→run_started 的工作流排队、run_started→最后任务完成的执行时间、各任务时长之和。
最后一项是观察到的占用秒数，不是平台账单分钟或金额。
缓存命中和实际账单缺失时保留 unrecorded。
只有同一 workflow、run_number 连续、运行尝试不重复且任务总数完整的至少 20 次样本才标记连续样本完整。
少于 20 次不输出经验 P95；不声称达到五分钟目标或节省比例。

当前保存的日志与不完整状态摘要不足以计算完整 CI 成本。
GitHub 服务限制没有解除，未产生新的远端时间戳导出。
工具的合成测试数据只验证计算/缺失/重复/连续性拒绝，不导入实际证据索引。
真实连续远端样本和使用前后成本比较保持待采集。

复现：

```bash
python -m tools.performance --baseline <完整 SHA> --candidate <完整 SHA> \
  --gil-python <普通 CPython> --free-threaded-python <FT CPython> \
  --samples 20 --iterations 10000 --runtime-only --threaded-only \
  --output <新目录>
python -m tools.ci_cost --input <完整 run/jobs 导出 JSON> --output <新 JSON>
```
