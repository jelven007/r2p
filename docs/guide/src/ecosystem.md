# The r2p ecosystem

This portion of the guide is dedicated to crates which are external to the main r2p project and provide additional functionality you might find useful.

These integrations originate in the upstream PyO3 ecosystem. Their package names
remain unchanged; integrations which exchange PyO3 types require separate
adaptation before they can be used with r2p.

Because these projects evolve independently of the r2p repository the content of these articles may fall out of date over time; please file issues on the r2p GitHub to alert maintainers when this is the case.
