# The r2p user guide

Welcome to the r2p user guide!
This book is a companion to [r2p's API docs]({{#R2P_DOCS_URL}}/r2p/index.html).
It contains examples and documentation to explain all of r2p's use cases in detail.

The rough order of material in this user guide is as follows:

1. Getting started
2. Wrapping Rust code for use from Python
3. How to use Python code from Rust
4. Remaining topics which go into advanced concepts in detail

Please choose from the chapters on the left to jump to individual topics, or continue below to start with r2p's README.
